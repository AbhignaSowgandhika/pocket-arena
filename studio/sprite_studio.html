Details

What is it?
Sets its stats: attackers hit hard, defenders have more HP, and so on.

Opened as a file on your computer. Use Save sprite file, then move the file into the game's assets/sprites folder. Use Open sprite file to edit one that's already there.

Tips

  • Draw it facing right. The game flips it for the other direction.
  • A dark outline makes it stand out on the grass.
  • Stick to 3 to 6 colors, with one darker shade for shadows.
  • Turn on Mirror for a symmetrical front-facing creature.
  • Leave a little empty space at the edges.
